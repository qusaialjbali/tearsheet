Star ratingStar rating

Five-star rating with hover preview, made of radio buttons and zero JavaScript.

Why it works: Each star is a labelled radio, so arrow keys work and screen readers announce “3 stars”. Stars are drawn with a CSS mask, not a font.

Try it:
Receipt: axe clean · contrast 17.41:1 · 1 tab stop · RTL ✓ · long text ✓
  • PASS axe, WCAG 2.1 A and AA: no violations in light or dark (10 rules passed).
  • PASS Tightest text contrast 17.41:1, where 4.5:1 is needed (dark).
  • PASS Still passes contrast with tokens fitted to a yellow brand colour.
  • PASS Right-to-left with Arabic sample text fits a 390px phone.
  • PASS Every string 40% longer still fits a 390px phone.
  • PASS Only short hover and focus transitions (under 300ms).

Tab order

  1. radio "4 stars" [checked]

What assistive tech is given

- group "Rate this component":
  - text: Rate this component
  - radio "5 stars"
  - text: 5 stars
  - radio "4 stars" [checked]
  - text: 4 stars
  - radio "3 stars"
  - text: 3 stars
  - radio "2 stars"
  - text: 2 stars
  - radio "1 star"
  - text: 1 star

Automated checks in CI (axe in Chromium, reduced motion on). They catch a lot, not everything: still try it with a screen reader.

See it in the zine npx -y tearsheet add star-rating

Needs the shared tokens.css once per project.
