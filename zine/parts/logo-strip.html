Logo stripLogo strip

A quiet row of customer logos under a plain label, greyed so it never competes with the content.

Why it works: Only show logos you have permission to show. These are made-up wordmarks. Keep logos monochrome and the same visual weight.

Try it:
Receipt: axe clean · contrast 4.62:1 · 0 tab stops · RTL ✓ · long text ✓
  • PASS axe, WCAG 2.1 A and AA: no violations in light or dark (14 rules passed).
  • PASS Tightest text contrast 4.62:1, where 4.5:1 is needed (light).
  • PASS Still passes contrast with tokens fitted to a yellow brand colour.
  • PASS Right-to-left with Arabic sample text fits a 390px phone.
  • PASS Every string 40% longer still fits a 390px phone.
  • PASS No motion.

Tab order: nothing here takes focus (it is content, not controls).

What assistive tech is given

- region "Used by teams at (example names)":
  - paragraph: Used by teams at (example names)
  - list:
    - listitem: northwind
    - listitem: GLOBEX
    - listitem: Initech
    - listitem: umbra&co
    - listitem: HOOLI

Automated checks in CI (axe in Chromium, reduced motion on). They catch a lot, not everything: still try it with a screen reader.

See it in the zine npx -y tearsheet add logo-strip

Needs the shared tokens.css once per project.
