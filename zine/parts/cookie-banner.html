Honest cookie bannerHonest cookie banner

A consent banner where saying no is exactly as easy as saying yes.

Why it works: Reject and Accept get equal size and weight, and nothing is pre-ticked. That is not just polite: GDPR guidance treats a buried “reject” as invalid consent. It never blocks the page.

Try it:
Receipt: axe clean · contrast 5.93:1 · 3 tab stops · RTL ✓ · long text ✓
  • PASS axe, WCAG 2.1 A and AA: no violations in light or dark (16 rules passed).
  • PASS Tightest text contrast 5.93:1, where 4.5:1 is needed (dark).
  • PASS Still passes contrast with tokens fitted to a yellow brand colour.
  • PASS Right-to-left with Arabic sample text fits a 390px phone.
  • PASS Every string 40% longer still fits a 390px phone.
  • PASS Only short hover and focus transitions (under 300ms).

Tab order

  1. button "Reject optional"
  2. button "Accept all"

What assistive tech is given

- region "Cookies, briefly":
  - heading "Cookies, briefly" [level=2]
  - paragraph: We use essential cookies to keep you signed in. With your OK we would also like to measure which pages are useful. No ads, no selling data.
  - button "Reject optional"
  - button "Accept all"
  - link "Choose what to allow":
    - /url: "#"

Automated checks in CI (axe in Chromium, reduced motion on). They catch a lot, not everything: still try it with a screen reader.

/* tearsheet cookie-banner v6a7ef958 · https://qusaialjbali.github.io/tearsheet/zine/parts/cookie-banner.html */
function setup(root) {
  const done = root.querySelector('.consent-done');
  const buttons = root.querySelectorAll('[data-choice]');
  const onChoice = (e) => {
    const accepted = e.currentTarget.dataset.choice === 'accept';
    // Store the choice, e.g. localStorage.setItem('consent', accepted ? 'all' : 'essential')
    done.textContent = accepted ? 'Thanks. Optional cookies are on; change this any time in Settings.' : 'Done. Only essential cookies will be used.';
  };
  buttons.forEach((b) => b.addEventListener('click', onChoice));
  return () => buttons.forEach((b) => b.removeEventListener('click', onChoice));
}

document.querySelectorAll(".consent").forEach(setup);
