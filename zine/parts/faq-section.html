FAQ sectionFAQ section

Questions people actually ask, in two columns: a heading and contact route on one side, answers on the other.

Why it works: Write questions in the reader’s words. Always end with a way to ask something that is not listed. <details> keeps it accessible and searchable with Ctrl+F.

Try it:
Receipt: axe clean · contrast 5.93:1 · 5 tab stops · RTL ✓ · long text ✓
  • PASS axe, WCAG 2.1 A and AA: no violations in light or dark (11 rules passed).
  • PASS Tightest text contrast 5.93:1, where 4.5:1 is needed (dark).
  • PASS Still passes contrast with tokens fitted to a yellow brand colour.
  • PASS Right-to-left with Arabic sample text fits a 390px phone.
  • PASS Every string 40% longer still fits a 390px phone.
  • PASS Only short hover and focus transitions (under 300ms).

Tab order

  1. link "Ask us":
  2. text: Is it really free? +
  3. text: Do my friends need an account? +
  4. text: Can I export my data? +
  5. text: Which currencies do you support? +

What assistive tech is given

- heading "Questions, answered" [level=2]
- paragraph:
  - text: Can’t find yours?
  - link "Ask us":
    - /url: "#"
  - text: . A person replies within a day.
- group:
  - text: Is it really free? +
  - paragraph: Yes, for groups of up to five people. Bigger groups pay $3 a month per group, not per person.
- group: Do my friends need an account? +
- group: Can I export my data? +
- group: Which currencies do you support? +

Automated checks in CI (axe in Chromium, reduced motion on). They catch a lot, not everything: still try it with a screen reader.

See it in the zine npx -y tearsheet add faq-section

Needs the shared tokens.css once per project.

  </div>
</section>
