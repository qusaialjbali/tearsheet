Progress & spinnerProgress & spinner

Determinate progress bar and an indeterminate spinner, both announced to assistive tech.

Why it works: Use a progress bar when you know how long something takes, a spinner for short unknown waits (under ~3 s), and skeletons for loading page content.

Try it:
Receipt: axe clean · contrast 6.7:1 · 0 tab stops · RTL ✓ · long text ✓
  • PASS axe, WCAG 2.1 A and AA: no violations in light or dark (18 rules passed).
  • PASS Tightest text contrast 6.7:1, where 4.5:1 is needed (light).
  • PASS Still passes contrast with tokens fitted to a yellow brand colour.
  • PASS Right-to-left with Arabic sample text fits a 390px phone.
  • PASS Every string 40% longer still fits a 390px phone.
  • PASS 1 looping animation keeps running with reduced motion on (slowed or essential, like a loading bar).

Tab order: nothing here takes focus (it is content, not controls).

What assistive tech is given

- text: Uploading report.pdf 64%
- progressbar "Uploading report.pdf"
- status: Loading results…

Automated checks in CI (axe in Chromium, reduced motion on). They catch a lot, not everything: still try it with a screen reader.

See it in the zine npx -y tearsheet add progress

Needs the shared tokens.css once per project.

HTML + CSS
index.html
<!-- tearsheet progress ve01cdc66 · https://qusaialjbali.github.io/tearsheet/zine/parts/progress.html -->
<div class="progress-demo">
  <div class="progress-block">
    <div class="progress-head">
      <span id="upload-label">Uploading report.pdf</span>
      <span class="progress-value">64%</span>
    </div>
    <div class="progress" role="progressbar" aria-labelledby="upload-label" aria-valuenow="64" aria-valuemin="0" aria-valuemax="100">
      <div class="progress-bar" style="width: 64%"></div>
    </div>
  </div>
  <div class="loading" role="status">
    <span class="spinner" aria-hidden="true"></span>
    <span>Loading results…</span>
  </div>
</div>
styles.css
/* tearsheet progress ve01cdc66 · https://qusaialjbali.github.io/tearsheet/zine/parts/progress.html */
.progress-demo { display: grid; gap: 28px; width: 100%; max-width: 400px; }
.progress-head {
  display: flex;
  justify-content: space-between;
  margin-bottom: 8px;
  font-size: 14px;
  font-weight: 500;
  color: var(--ui-text);
}
.progress-value { color: var(--ui-muted); font-variant-numeric: tabular-nums; }
.progress {
  height: 8px;
  overflow: hidden;
  border-radius: 999px;
  background: var(--ui-surface-2);
}
.progress-bar {
  height: 100%;
  border-radius: inherit;
  background: var(--ui-accent);
  transition: width 0.3s ease;
}
.loading { display: flex; align-items: center; gap: 10px; font-size: 14px; color: var(--ui-muted); }
.spinner {
  width: 20px;
  height: 20px;
  border-radius: 50%;
  border: 2.5px solid var(--ui-surface-2);
  border-top-color: var(--ui-accent);
  animation: spin 0.8s linear infinite;
}
@keyframes spin { to { transform: rotate(360deg); } }
@media (prefers-reduced-motion: reduce) {
  .spinner { animation-duration: 2s; }
}
