Plan comparisonPlan comparison

Plans side by side with yes/no marks that read as words to screen readers, and the recommended plan marked.

Why it works: Each tick and cross has hidden text (“Included”, “Not included”), so the table makes sense without seeing the icons. The recommended column is labelled in words, not just colour.

Try it:
Receipt: axe clean · contrast 5.35:1 · 0 tab stops · RTL ✓ · long text ✓
  • PASS axe, WCAG 2.1 A and AA: no violations in light or dark (8 rules passed).
  • PASS Tightest text contrast 5.35:1, where 4.5:1 is needed (dark).
  • PASS Still passes contrast with tokens fitted to a yellow brand colour.
  • PASS Right-to-left with Arabic sample text fits a 390px phone.
  • PASS Every string 40% longer still fits a 390px phone.
  • PASS No motion.

Tab order: nothing here takes focus (it is content, not controls).
