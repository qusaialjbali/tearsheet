Issue 01: Interface parts

Actions

  • Buttons Primary, secondary, ghost and destructive buttons with hover, focus and disabled states.
  • Toggle button group A formatting toolbar of joined icon buttons that each switch on and off.
  • Split button A main action with a small menu of related alternatives attached to its side.
  • Icon buttons Round and square icon-only buttons in three sizes, plus a favourite toggle.
  • Loading button A button that shows its work: idle, saving with a spinner, then a short confirmation.

Forms

  • Text field Labelled input with helper text and an error state wired up with aria-describedby.
  • Checkbox & switch Custom-styled native checkboxes and a toggle switch. Keyboard and screen-reader support stays native.
  • Select A native select restyled to match the text field, with a drawn chevron.
  • Radio cards Big, scannable choice cards built on native radio buttons.
  • Segmented control Switch between two to four views. Radios underneath, so it works without JavaScript.
  • Range slider Native range input with a filled track and a live value readout.
  • Number stepper Minus and plus buttons around a number field, clamped to a range.
  • File dropzone Drag files in or click to browse. A real file input underneath keeps it keyboard accessible.
  • Star rating Five-star rating with hover preview, made of radio buttons and zero JavaScript.
  • One-time code Six-box verification code that auto-advances, handles backspace and accepts a pasted or autofilled code.
  • Copy field Read-only value with a copy button that confirms in place and announces it.
  • Autocomplete A text field that suggests matching options as you type, with full keyboard control.
  • Tag input Type a word and press Enter or comma to turn it into a removable tag.
  • Date range Start and end dates using the native date input, styled to match, with the end kept after the start.
  • Multi-step form A short sign-up split into three steps with progress, back and next, and focus moved to each new step.
  • Textarea with counter A comment box that grows with its text and counts down the characters left.

Content

  • Card Content card with media, eyebrow, title, summary and a link footer.
  • Badges Compact status labels in neutral, accent and semantic tones.
  • Accordion Zero-JavaScript FAQ accordion built on <details> and <summary>.
  • Avatar group Overlapping initials avatars with an overflow count.
  • Data table Readable table with a caption, scoped headers, right-aligned numbers and status badges. Scrolls sideways on small screens.
  • Stat group A row of key numbers with labelled change, built as a description list.
  • Settings list Rows of settings mixing toggles, links to sub-pages and a destructive action.
  • Keyboard shortcuts A shortcut cheat sheet with properly styled <kbd> keys.
  • Activity timeline A vertical feed of events with machine-readable times.
  • Chat thread Message bubbles with grouping, timestamps, a typing indicator and a composer that sends.
  • Comment thread A discussion with one level of replies, author badges, relative times and quiet actions.
  • Code block A file-tabbed code snippet with line numbers, a highlighted line and a copy button.
  • Kanban column A board column of task cards with labels, assignees, due dates and a quick add.
  • Carousel A swipeable row of slides with previous/next buttons and a slide counter. It never auto-advances.
  • Lightbox gallery A thumbnail grid that opens each picture large in a dialog, with arrow keys to flip through.

Data

  • Sortable table Click a column header to sort; click again to reverse. Row checkboxes select, with a select-all.
  • Bar chart Horizontal bars drawn with plain HTML and CSS, every value printed next to its bar.
  • Line chart A lightweight SVG line chart with gridlines, axis labels and a highlighted latest point.
  • Donut chart A CSS conic-gradient donut with a total in the middle and a legend that carries the real numbers.
  • Sparkline stats Compact metric tiles, each with a tiny trend line and its change spelled out.
  • Month calendar A month grid with today marked, event dots, and arrow-key navigation between days.
  • File tree A nested folder tree built from <details>, with file and folder icons and no JavaScript.
  • Details list Label-and-value pairs for an order or a profile, with one value you can edit in place.

Feedback

  • Alerts Info, success, warning and error banners. Each pairs color with an icon and text, so meaning never relies on color alone.
  • Toast notification Non-blocking confirmation that appears briefly in a live region and can be dismissed.
  • Progress & spinner Determinate progress bar and an indeterminate spinner, both announced to assistive tech.
  • Skeleton loader Shimmering placeholder that mirrors the shape of the content it stands in for.
  • Empty state Explains why a view is empty and offers the next step.

Navigation

  • Tabs Accessible tabs following the WAI-ARIA pattern, with arrow-key navigation and roving tabindex.
  • Navigation bar Responsive site header with brand, links, actions and a no-JS mobile menu.
  • Breadcrumb Shows where the page sits in the site hierarchy, using an ordered list.
  • Pagination Page links with previous/next, a current page and a gap for skipped pages.
  • Steps indicator Checkout-style progress through a fixed sequence, with done, current and upcoming steps.

Overlays

  • Modal dialog Confirmation dialog built on the native <dialog> element: focus trapping, Esc to close and a backdrop come built in.
  • Tooltip CSS-only tooltip that shows on hover and on keyboard focus.
  • Dropdown menu An actions menu built on <details>, with icons and a separated destructive item.
  • Side drawer A panel that slides in from the edge for filters or secondary tasks, built on <dialog>.
  • Popover A small anchored card for extra detail, using the native popover attribute: no JavaScript.
  • Context menu Right-click (or long-press, or the Menu key) on the card to get a menu of actions at the pointer.
  • Honest cookie banner A consent banner where saying no is exactly as easy as saying yes.
  • Command palette A searchable list of actions on Ctrl/⌘ K, driven entirely by the keyboard.

Sections

  • Pricing card Plan card with price, feature list and a single call to action.
  • Hero, centred An opening section with one clear promise, a short explanation and one main action.
  • Hero with signup A hero whose main action is a working email field, with an honest product preview beside it.
  • Feature grid Six features as short, scannable blocks, each leading with what it does for the reader.
  • Testimonial One large, specific quote with the person’s name, role and a photo slot.
  • Logo strip A quiet row of customer logos under a plain label, greyed so it never competes with the content.
  • FAQ section Questions people actually ask, in two columns: a heading and contact route on one side, answers on the other.
  • Call-to-action band A closing band in the accent colour that repeats the main action once more.
  • Newsletter signup An email signup that says exactly what you will get and how often, with inline validation.
  • Plan comparison Plans side by side with yes/no marks that read as words to screen readers, and the recommended plan marked.
  • Changelog Release notes grouped by date, each change tagged New, Improved or Fixed.
  • Site footer A footer with the brand line, grouped links, a language picker and the legal row.
  • 404 page A not-found page that admits the mistake, offers a search and the three most likely destinations.
  • Pricing tiers Three plans side by side with a monthly/yearly switch that updates every price.

Weird

  • Magnetic button The button leans toward your cursor before you reach it, and its label lags behind for depth.
  • Split-flap board An airport departures board: every letter clatters through the alphabet until it lands.
  • Odometer counter A mechanical counter whose digit wheels roll into place, each a beat after the last.
  • Holographic card A foil membership card that tilts in 3D and throws a moving rainbow sheen as you move across it.
  • Decoder text A headline that decrypts itself from noise, one letter locking in at a time.
  • Hold to confirm A destructive button you have to press and hold, so a stray click can never delete anything.
  • Elastic string slider A slider drawn as a guitar string: drag the thumb up or down and it bends, let go and it twangs back.
  • Orbit menu A floating action button that bursts six actions into orbit around itself.
  • Scratch card Scratch off a foil layer with your cursor or finger to reveal a hidden code.
  • Liquid progress A round tank that fills with a rolling wave as progress changes.
  • Rotary knob An amp-style dial you twist by dragging around it, scrolling, or with the arrow keys. It goes to eleven.
  • Password creature A little creature that covers its eyes while you type a password, peeks when you show it, and grins as it gets stronger.
  • Throwable tags Tags fall into a box under gravity. Grab one, fling it, and watch the pile settle.
  • Gooey switch A switch whose knob stretches like liquid as it slides, made with an SVG goo filter and zero JavaScript.
  • Idea slot machine Three reels spin and land one by one on a random brief: a mood, a colour and a component to build.
  • Typewriter terminal A terminal window that types out a short session line by line, with a blinking caret and a replay.
  • Vinyl player A record player UI: press play and the record spins, the tonearm drops and the track time runs.
  • Ink bleed menu Menu items flood with ink from exactly where your pointer enters, like a drop on blotting paper.
  • VHS glitch heading A heading that tears into red and cyan slices like a worn tape when you hover or press the button.
  • Ink trail pad Move across the pad and leave a trail of ink dots that spread and fade like wet riso ink.
  • Jelly button A button that squashes and wobbles like jelly when you press it, then settles.
  • Cube tabs Tabs where every panel is a face of a 3D cube that turns to show the one you pick.
