Newsletter signupNewsletter signup

An email signup that says exactly what you will get and how often, with inline validation.

Why it works: Say what is in it and how often (“one email a month”). No pre-ticked boxes, and the privacy line is right next to the button, not in a footer.

Try it:
Receipt: axe clean · contrast 6.28:1 · 2 tab stops · RTL ✓ · long text ✓
  • PASS axe, WCAG 2.1 A and AA: no violations in light or dark (17 rules passed).
  • PASS Tightest text contrast 6.28:1, where 4.5:1 is needed (light).
  • PASS Still passes contrast with tokens fitted to a yellow brand colour.
  • PASS Right-to-left with Arabic sample text fits a 390px phone.
  • PASS Every string 40% longer still fits a 390px phone.
  • PASS No motion.

Tab order

  1. textbox "Email address":
  2. button "Subscribe"

What assistive tech is given

- heading "One useful email a month" [level=2]
- paragraph: New components, one design rule explained, nothing else. Unsubscribe in one click.
- text: Email address
- textbox "Email address":
  - /placeholder: you@example.com
- button "Subscribe"
- paragraph: We only use your email for this newsletter.

Automated checks in CI (axe in Chromium, reduced motion on). They catch a lot, not everything: still try it with a screen reader.

See it in the zine npx -y tearsheet add newsletter

script.js
/* tearsheet newsletter v1fce2b0d · https://qusaialjbali.github.io/tearsheet/zine/parts/newsletter.html */
function setup(root) {
  const form = root.querySelector('form');
  const input = form.querySelector('input');
  const msg = root.querySelector('.news-msg');
  const onSubmit = (e) => {
    e.preventDefault();
    const ok = Boolean(input.value) && input.checkValidity();
    input.setAttribute('aria-invalid', String(!ok));
    msg.className = 'news-msg ' + (ok ? 'is-ok' : 'is-error');
    msg.textContent = ok ? 'Almost done: confirm the link we just emailed you.' : 'That email looks incomplete. Try name@example.com.';
    if (!ok) input.focus();
  };
  form.addEventListener('submit', onSubmit);
  return () => form.removeEventListener('submit', onSubmit);
}

document.querySelectorAll(".news").forEach(setup);

export function Newsletter() {
  const ref = useRef(null);

}
