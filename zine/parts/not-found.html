404 page404 page

A not-found page that admits the mistake, offers a search and the three most likely destinations.

Why it works: Do not blame the visitor. Give them a search box and the few places they most likely meant to go, and log 404s so you can fix the broken links.

Try it:
Receipt: axe clean · contrast 5.93:1 · 5 tab stops · RTL ✓ · long text ✓
  • PASS axe, WCAG 2.1 A and AA: no violations in light or dark (19 rules passed).
  • PASS Tightest text contrast 5.93:1, where 4.5:1 is needed (dark).
  • PASS Still passes contrast with tokens fitted to a yellow brand colour.
  • PASS Right-to-left with Arabic sample text fits a 390px phone.
  • PASS Every string 40% longer still fits a 390px phone.
  • PASS No motion.

Tab order

  1. searchbox "Search the site"
  2. button "Search"
  3. link "Home":
  4. link "Help centre":
  5. link "Contact support":

What assistive tech is given

- heading "That page has wandered off." [level=1]
- paragraph: The link may be old, or we moved something. Try a search, or head somewhere useful.
- search:
  - text: Search the site
  - searchbox "Search the site"
  - button "Search"
- list:
  - listitem:
    - link "Home":
      - /url: "#"
  - listitem:
    - link "Help centre":
      - /url: "#"
  - listitem:
    - link "Contact support":
      - /url: "#"

Automated checks in CI (axe in Chromium, reduced motion on). They catch a lot, not everything: still try it with a screen reader.

See it in the zine npx -y tearsheet add not-found

Needs the shared tokens.css once per project.
