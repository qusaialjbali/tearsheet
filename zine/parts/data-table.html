Data tableData table

Readable table with a caption, scoped headers, right-aligned numbers and status badges. Scrolls sideways on small screens.

Why it works: Right-align numbers and use tabular figures so digits line up. A <caption> names the table for screen-reader users.

Try it:
Receipt: axe clean · contrast 4.79:1 · 1 tab stop · RTL ✓ · long text ✓
  • PASS axe, WCAG 2.1 A and AA: no violations in light or dark (17 rules passed).
  • PASS Tightest text contrast 4.79:1, where 4.5:1 is needed (light).
  • PASS Still passes contrast with tokens fitted to a yellow brand colour.
  • PASS Right-to-left with Arabic sample text fits a 390px phone.
  • PASS Every string 40% longer still fits a 390px phone.
  • PASS No motion.

Automated checks in CI (axe in Chromium, reduced motion on). They catch a lot, not everything: still try it with a screen reader.
