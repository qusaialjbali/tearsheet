Cube tabsCube tabs

Tabs where every panel is a face of a 3D cube that turns to show the one you pick.

Why it works: It is the standard tabs pattern (arrow keys, roving focus), so only the visible face is exposed; the other faces are inert. With reduced motion the cube snaps instead of turning.

Try it:
Receipt: axe clean · contrast 6.09:1 · 1 tab stop · RTL ✓ · long text ✓
  • PASS axe, WCAG 2.1 A and AA: no violations in light or dark (19 rules passed).
  • PASS Tightest text contrast 6.09:1, where 4.5:1 is needed (light).
  • PASS Still passes contrast with tokens fitted to a yellow brand colour.
  • PASS Right-to-left with Arabic sample text fits a 390px phone.
  • PASS Every string 40% longer still fits a 390px phone.
  • PASS Movement stops or calms down with reduced motion on.

Tab order

  1. tab "What" [selected]

What assistive tech is given

- tablist "About the zine":
  - tab "What" [selected]
  - tab "Who"
  - tab "How"
  - tab "Why"
- tabpanel "What": What Free interface parts, printed in four formats.
- tabpanel "Who": Who Designers and developers, equally.
- tabpanel "How": How Pick a format, tear out the code, ship it.
- tabpanel "Why": Why Because good defaults should be free.

Automated checks in CI (axe in Chromium, reduced motion on). They catch a lot, not everything: still try it with a screen reader.

See it in the zine npx -y tearsheet add cube-tabs

script.js
/* tearsheet cube-tabs v4eb762ab · https://qusaialjbali.github.io/tearsheet/zine/parts/cube-tabs.html */
function setup(root) {
  const tabs = [...root.querySelectorAll('[role="tab"]')];
  const faces = [...root.querySelectorAll('[role="tabpanel"]')];
  const body = root.querySelector('.cube-body');
  const select = (i, focus) => {
    tabs.forEach((t, n) => { t.setAttribute('aria-selected', String(n === i)); t.tabIndex = n === i ? 0 : -1; });
    faces.forEach((f, n) => (f.inert = n !== i));
    body.style.setProperty('--turn', -90 * i + 'deg');
    if (focus) tabs[i].focus();
  };
  const onClick = (e) => select(tabs.indexOf(e.currentTarget));
  const onKey = (e) => {
    const i = tabs.indexOf(document.activeElement);
    const d = { ArrowRight: 1, ArrowLeft: -1 }[e.key];
    if (i < 0 || !d) return;
    e.preventDefault();
    select((i + d + tabs.length) % tabs.length, true);
  };
  tabs.forEach((t) => t.addEventListener('click', onClick));
  root.addEventListener('keydown', onKey);
  return () => { tabs.forEach((t) => t.removeEventListener('click', onClick)); root.removeEventListener('keydown', onKey); };
}

document.querySelectorAll(".cube").forEach(setup);
