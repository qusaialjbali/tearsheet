Gooey switchGooey switch

A switch whose knob stretches like liquid as it slides, made with an SVG goo filter and zero JavaScript.

Why it works: Underneath it is a native checkbox with role="switch", so keyboard, forms and screen readers work as normal. The goo is two blobs, one lagging behind the other, melted together by the filter.

Try it:
Receipt: axe clean · contrast 17.41:1 · 1 tab stop · RTL ✓ · long text ✓
  • PASS axe, WCAG 2.1 A and AA: no violations in light or dark (13 rules passed).
  • PASS Tightest text contrast 17.41:1, where 4.5:1 is needed (dark).
  • PASS Still passes contrast with tokens fitted to a yellow brand colour.
  • PASS Right-to-left with Arabic sample text fits a 390px phone.
  • PASS Every string 40% longer still fits a 390px phone.
  • PASS Movement stops or calms down with reduced motion on.
