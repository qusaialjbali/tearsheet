Radio cardsRadio cards

Big, scannable choice cards built on native radio buttons.

Why it works: The whole card is the label, so the click target is huge. Arrow keys move between options because they are real radios in one group.

Try it:
Receipt: axe clean · contrast 5.99:1 · 1 tab stop · RTL ✓ · long text ✓
  • PASS axe, WCAG 2.1 A and AA: no violations in light or dark (9 rules passed).
  • PASS Tightest text contrast 5.99:1, where 4.5:1 is needed (light).
  • PASS Still passes contrast with tokens fitted to a yellow brand colour.
  • PASS Right-to-left with Arabic sample text fits a 390px phone.
  • PASS Every string 40% longer still fits a 390px phone.
  • PASS Only short hover and focus transitions (under 300ms).

Tab order

  1. radio "Pro Unlimited projects · email help $12/mo" [checked]

What assistive tech is given

- group "Choose a plan":
  - text: Choose a plan
  - radio "Hobby 1 project · community help Free"
  - text: Hobby 1 project · community help Free
  - radio "Pro Unlimited projects · email help $12/mo" [checked]
  - text: Pro Unlimited projects · email help $12/mo
  - radio "Team Shared workspace · priority help $29/mo"
  - text: Team Shared workspace · priority help $29/mo

Automated checks in CI (axe in Chromium, reduced motion on). They catch a lot, not everything: still try it with a screen reader.

See it in the zine npx -y tearsheet add radio-cards

Needs the shared tokens.css once per project.
