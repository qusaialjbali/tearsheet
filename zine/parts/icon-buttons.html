Icon buttonsIcon buttons

Round and square icon-only buttons in three sizes, plus a favourite toggle.

Why it works: An icon button must have an aria-label, and its hit area stays at least 40px even when the icon is small.

Try it:
Receipt: axe clean · contrast n/a · 5 tab stops · RTL ✓ · long text ✓
  • PASS axe, WCAG 2.1 A and AA: no violations in light or dark (13 rules passed).
  • PASS No text to measure for contrast.
  • PASS Still passes contrast with tokens fitted to a yellow brand colour.
  • PASS Right-to-left with Arabic sample text fits a 390px phone.
  • PASS Every string 40% longer still fits a 390px phone.
  • PASS Only short hover and focus transitions (under 300ms).

Tab order

  1. button "Edit"
  2. button "Share"
  3. button "Add item"
  4. button "Settings"
  5. button "Add to favourites"

What assistive tech is given

- button "Edit"
- button "Share"
- button "Add item"
- button "Settings"
- button "Add to favourites"

Automated checks in CI (axe in Chromium, reduced motion on). They catch a lot, not everything: still try it with a screen reader.

See it in the zine npx -y tearsheet add icon-buttons

Needs the shared tokens.css once per project.

function setup(root) {
  const fav = root.querySelector('.fav');
  const onFav = () => {
    const on = fav.getAttribute('aria-pressed') !== 'true';
    fav.setAttribute('aria-pressed', String(on));
    fav.setAttribute('aria-label', on ? 'Remove from favourites' : 'Add to favourites');
  };
  fav.addEventListener('click', onFav);
  return () => fav.removeEventListener('click', onFav);
}

document.querySelectorAll(".icon-row").forEach(setup);
