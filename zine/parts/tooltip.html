TooltipTooltip

CSS-only tooltip that shows on hover and on keyboard focus.

Why it works: Tooltips hold short, non-essential hints. Touch screens have no hover, so never hide required information in one.

Try it:
Receipt: axe clean · contrast n/a · 1 tab stop · RTL ✓ · long text ✓
  • PASS axe, WCAG 2.1 A and AA: no violations in light or dark (17 rules passed).
  • PASS No text to measure for contrast.
  • PASS Still passes contrast with tokens fitted to a yellow brand colour.
  • PASS Right-to-left with Arabic sample text fits a 390px phone.
  • PASS Every string 40% longer still fits a 390px phone.
  • PASS Only short hover and focus transitions (under 300ms).

Tab order

  1. button "Billing help": "?"

What assistive tech is given

- button "Billing help": "?"
- tooltip "You’re billed on the 1st of each month."

Automated checks in CI (axe in Chromium, reduced motion on). They catch a lot, not everything: still try it with a screen reader.

See it in the zine npx -y tearsheet add tooltip

Needs the shared tokens.css once per project.

.tip-trigger {
  display: grid;
  place-items: center;
  width: 32px;
  height: 32px;

  font-weight: 700;
  color: var(--ui-muted);
  background: var(--ui-surface-2);
  border: 1px solid var(--ui-border);
  border-radius: 50%;
  cursor: help;
}
.tip-trigger:focus-visible { outline: none; box-shadow: var(--ui-focus); }
.tip-bubble {
  position: absolute;
  bottom: calc(100% + 10px);
  left: 50%;
  width: max-content;
  max-width: 240px;
  padding: 8px 12px;
  font-size: 13px;
  line-height: 1.4;
  color: var(--ui-bg);
  background: var(--ui-text);
  border-radius: 6px;
  pointer-events: none;
  opacity: 0;
  transform: translate(-50%, 4px);
  transition: opacity 0.15s, transform 0.15s;
}
.tip-bubble::after {
  content: "";
  position: absolute;
  top: 100%;
  left: 50%;
  border: 6px solid transparent;
  border-top-color: var(--ui-text);
  transform: translateX(-50%);
}
.tip:hover .tip-bubble,
.tip:focus-within .tip-bubble { opacity: 1; transform: translate(-50%, 0); }
