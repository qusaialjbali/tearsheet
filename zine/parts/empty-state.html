Empty stateEmpty state

Explains why a view is empty and offers the next step.

Why it works: An empty screen is a chance to teach. Say what will appear here and give one clear way to get started.

Try it:
Receipt: axe clean · contrast 6.28:1 · 2 tab stops · RTL ✓ · long text ✓
  • PASS axe, WCAG 2.1 A and AA: no violations in light or dark (9 rules passed).
  • PASS Tightest text contrast 6.28:1, where 4.5:1 is needed (light).
  • PASS Still passes contrast with tokens fitted to a yellow brand colour.
  • PASS Right-to-left with Arabic sample text fits a 390px phone.
  • PASS Every string 40% longer still fits a 390px phone.
  • PASS Only short hover and focus transitions (under 300ms).

Tab order

  1. button "New project"
  2. button "Browse templates"

What assistive tech is given

- heading "No projects yet" [level=3]
- paragraph: Projects you create will show up here. Start from a template or a blank canvas.
- button "New project"
- button "Browse templates"

Automated checks in CI (axe in Chromium, reduced motion on). They catch a lot, not everything: still try it with a screen reader.

See it in the zine npx -y tearsheet add empty-state

Needs the shared tokens.css once per project.
