Orbit menuOrbit menu

A floating action button that bursts six actions into orbit around itself.

Why it works: Closed items are hidden from the tab order. Esc closes and returns focus to the button. Each item has a text label, not just an icon.

Try it:
Receipt: axe clean · contrast n/a · 1 tab stop · RTL ✓ · long text ✓
  • PASS axe, WCAG 2.1 A and AA: no violations in light or dark (15 rules passed).
  • PASS No text to measure for contrast.
  • PASS Still passes contrast with tokens fitted to a yellow brand colour.
  • PASS Right-to-left with Arabic sample text fits a 390px phone.
  • PASS Every string 40% longer still fits a 390px phone.
  • PASS Movement stops or calms down with reduced motion on.

Tab order

  1. button "Quick add"

What assistive tech is given

- list
- button "Quick add"

Automated checks in CI (axe in Chromium, reduced motion on). They catch a lot, not everything: still try it with a screen reader.

script.js
/* tearsheet orbit-menu v294ea01e · https://qusaialjbali.github.io/tearsheet/zine/parts/orbit-menu.html */
function setup(root) {
  const toggle = root.querySelector('.orbit-toggle');
  const items = root.querySelectorAll('.orbit-item');

  const setOpen = (open) => {
    root.classList.toggle('is-open', open);
    toggle.setAttribute('aria-expanded', String(open));
    toggle.setAttribute('aria-label', open ? 'Close quick add' : 'Quick add');
  };
  const onToggle = () => setOpen(!root.classList.contains('is-open'));
  const onKey = (e) => {
    if (e.key === 'Escape' && root.classList.contains('is-open')) {
      setOpen(false);
      toggle.focus();
    }
  };
  const onItem = () => {
    setOpen(false);
    toggle.focus();
  };

  toggle.addEventListener('click', onToggle);
  root.addEventListener('keydown', onKey);
  items.forEach((i) => i.addEventListener('click', onItem));
  return () => {
    toggle.removeEventListener('click', onToggle);
    root.removeEventListener('keydown', onKey);
    items.forEach((i) => i.removeEventListener('click', onItem));
  };
}

document.querySelectorAll(".orbit").forEach(setup);
