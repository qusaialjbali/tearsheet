SelectSelect

A native select restyled to match the text field, with a drawn chevron.

Why it works: Keep the native <select>: it gets the right picker on every phone, works with autofill and needs no JavaScript. Use it for 5 to 15 options; fewer than 5 read better as radios.

Try it:
Receipt: axe clean · contrast 16.1:1 · 1 tab stop · RTL ✓ · long text ✓
  • PASS axe, WCAG 2.1 A and AA: no violations in light or dark (12 rules passed).
  • PASS Tightest text contrast 16.1:1, where 4.5:1 is needed (dark).
  • PASS Still passes contrast with tokens fitted to a yellow brand colour.
  • PASS Right-to-left with Arabic sample text fits a 390px phone.
  • PASS Every string 40% longer still fits a 390px phone.
  • PASS No motion.

Tab order

  1. combobox "Country":

What assistive tech is given

- text: Country
- combobox "Country":
  - option "Canada" [selected]
  - option "Germany"
  - option "Japan"
  - option "Jordan"
  - option "Mexico"
  - option "United Kingdom"

Automated checks in CI (axe in Chromium, reduced motion on). They catch a lot, not everything: still try it with a screen reader.

See it in the zine npx -y tearsheet add select

Needs the shared tokens.css once per project.
