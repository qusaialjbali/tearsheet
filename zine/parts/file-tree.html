File treeFile tree

A nested folder tree built from <details>, with file and folder icons and no JavaScript.

Why it works: Each folder is a native disclosure, so it works with keyboard and screen readers out of the box. For thousands of nodes, switch to the full ARIA tree pattern with roving focus.

Try it:
Receipt: axe clean · contrast 5.35:1 · 9 tab stops · RTL ✓ · long text ✓
  • PASS axe, WCAG 2.1 A and AA: no violations in light or dark (16 rules passed).
  • PASS Tightest text contrast 5.35:1, where 4.5:1 is needed (dark).
  • PASS Still passes contrast with tokens fitted to a yellow brand colour.
  • PASS Right-to-left with Arabic sample text fits a 390px phone.
  • PASS Every string 40% longer still fits a 390px phone.
  • PASS No motion.

See it in the zine npx -y tearsheet add file-tree

Needs the shared tokens.css once per project.
