Keyboard shortcutsKeyboard shortcuts

A shortcut cheat sheet with properly styled <kbd> keys.

Why it works: Use the <kbd> element for keys. Show the platform-correct modifier (Ctrl on Windows, ⌘ on Mac) when you can detect it.

Try it:
Receipt: axe clean · contrast 16.1:1 · 0 tab stops · RTL ✓ · long text ✓
  • PASS axe, WCAG 2.1 A and AA: no violations in light or dark (8 rules passed).
  • PASS Tightest text contrast 16.1:1, where 4.5:1 is needed (dark).
  • PASS Still passes contrast with tokens fitted to a yellow brand colour.
  • PASS Right-to-left with Arabic sample text fits a 390px phone.
  • PASS Every string 40% longer still fits a 390px phone.
  • PASS No motion.

Tab order: nothing here takes focus (it is content, not controls).

What assistive tech is given

- term: Search everything
- definition: Ctrl K
- term: Copy component
- definition: Ctrl Shift C
- term: Switch theme
- definition: Shift D
- term: Close dialog
- definition: Esc

Automated checks in CI (axe in Chromium, reduced motion on). They catch a lot, not everything: still try it with a screen reader.

See it in the zine npx -y tearsheet add keyboard-shortcuts

Needs the shared tokens.css once per project.
