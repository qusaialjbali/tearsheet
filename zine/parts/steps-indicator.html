Steps indicatorSteps indicator

Checkout-style progress through a fixed sequence, with done, current and upcoming steps.

Why it works: Mark the current step with aria-current="step" and tell screen readers which steps are complete in words, not only with a check mark.

Try it:
Receipt: axe clean · contrast 17.41:1 · 0 tab stops · RTL ✓ · long text ✓
  • PASS axe, WCAG 2.1 A and AA: no violations in light or dark (14 rules passed).
  • PASS Tightest text contrast 17.41:1, where 4.5:1 is needed (dark).
  • PASS Still passes contrast with tokens fitted to a yellow brand colour.
  • PASS Right-to-left with Arabic sample text fits a 390px phone.
  • PASS Every string 40% longer still fits a 390px phone.
  • PASS No motion.

Tab order: nothing here takes focus (it is content, not controls).

What assistive tech is given

- list:
  - listitem: Cart (completed)
  - listitem: Shipping (completed)
  - listitem: 3 Payment
  - listitem: 4 Review

Automated checks in CI (axe in Chromium, reduced motion on). They catch a lot, not everything: still try it with a screen reader.

See it in the zine npx -y tearsheet add steps-indicator

Needs the shared tokens.css once per project.
