    Back page: the tokens

    Every component reads its ink from one sheet of CSS custom properties. Swap the colours once and the whole issue reprints itself.

    2. Tear out a component in your format.
    3. Change --ui-accent, the radius and the font, or let the brand fitter do it: one colour in, contrast-checked light and dark tokens out. Add data-theme="dark" to <html> for dark.

    Give it to your agent

    Your AI coding assistant can use this issue too. Pick whichever your tools understand: all three hand over the same 98 components, the tokens and the design rules.

    1Point it at a link

    Works with any agent that can read a web page. Paste the link into your prompt, for example: “Use Tearsheet from this link for the date picker.”

    llms.txt
    https://qusaialjbali.github.io/tearsheet/llms.txt

    Behind it: a JSON index and every component as Markdown or JSON, in all four formats.

    2Run the command

    Writes components straight into a project, in the framework it finds in package.json. Needs Node 18 or newer; nothing to install first.

    terminal
    npx tearsheet add modal

    Also list, search date, show tabs --format vue, tokens --accent "#e11d48", guide forms, audit src to check your own UI against the guide, and diff to see what changed since you copied a part.

    3Connect over MCP

    Add this to the MCP settings of your editor or agent app. It gets tools to search components, fetch their code, read the tokens and design rules, fit tokens to a brand colour, and review the UI code it writes.

    mcp config
    {
  "mcpServers": {
    "tearsheet": {
      "command": "npx",
      "args": ["-y", "tearsheet", "mcp"]
    }
  }
}

    The top-level key differs between apps (some call it servers). On Windows, if npx is not found, use "command": "cmd" with "/c", "npx" at the start of args.
